# Autocomplete

The extension provides completion items for:

- language keywords
- snippets for common structures
- runtime namespaces such as `System` and `Develoment`
- runtime members like `System.Output`, `System.ReadFile`, `System.Server`, and more
- names declared in the current file

Examples:

- type `fname` to insert a function template
- type `System.` to browse runtime members
- type `Develoment.` to see test helpers
- type a local identifier prefix to complete symbols declared in the file
